# Домашнее задание к уроку № 7 «Неочевидный спектр документации»

## В VK WorkSpace 26.3 удаление учётных записей стало обратимым

*9 ноября опубликовано описание обновления релиза VK WorkSpace 26.3. Одно из главных изменений – корзина пользователей: удалённую учётную запись теперь можно восстановить вместе с данными.*

Перенос учётной записи в корзину не удаляет данные пользователя из сервисов. Они удаляются безвозвратно только после окончательного удаления учётной записи администратором.

Новый раздел расположен в панели администрирования. В нём можно искать пользователей, выбирать сразу несколько записей, восстанавливать их или удалять окончательно. Срок хранения настраивается в конфигурации, а количество записей в корзине не ограничено. Все операции – перенос, восстановление и окончательное удаление – попадают в журнал аудита. Корзина также принимает учётные записи, удалённые при импорте из CSV. Исключение составляют учётные записи, удалённые через интеграцию с Active Directory (AD): в корзину они не попадают.

В релиз вошли и другие новые функции. В Диске VK WorkSpace администратор домена теперь может передать другому пользователю права владения личными папками и файлами сотрудника вместе с настройками доступа. Почтовые вложения при этом не передаются. Для внутреннего редактора Р7 добавлено подключение по API. В Доске VK WorkSpace появились дублирование досок без комментариев, мини-карта для навигации и экспорт в JPG, PNG, CSV и PDF. Эти возможности доступны в веб-версии и десктопном приложении.

Помимо этого, обновление включает улучшения Почты, Диска и инфраструктуры, а также 18 исправлений уровня Critical/Blocker.
